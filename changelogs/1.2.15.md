# v1.2.15 - 2026-03-30

## Features

### Pull behind branches after status report

After the status report, the tool now offers to pull branches that are behind their remote.

**What's New**:

- Interactive prompt to pull behind branches once the status report is displayed
- Added a `make tag` workflow backed by `scripts/tag-version.sh` to tag new versions

**Impact**: Behind branches can be brought up to date in a single pass, without leaving the tool.
