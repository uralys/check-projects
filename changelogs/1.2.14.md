# v1.2.14 - 2026-02-17

## Features

### `--update` flag

Added a `--update` flag to check for a new release and install it on demand.

**What's New**:

- New `--update` flag performs a blocking update check and prompts to install if a newer version is available
- Simplified the updater internals around the new flow

**Impact**: Users can update the tool directly from the CLI without waiting for the background notification.
