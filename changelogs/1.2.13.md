# v1.2.13 - 2026-02-17

## Features

### Symlinked projects support

The scanner now correctly resolves symlinked directories when discovering and checking projects.

**What's New**:

- Symlinks are followed when scanning the projects root
- Git status, console reporter and TUI handle symlinked repositories consistently

**Impact**: Projects referenced through symlinks are no longer skipped or misreported.
