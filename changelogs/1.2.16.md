# v1.2.16 - 2026-06-08

## Bug Fixes

### Pull non-current branches through a temporary worktree

Branches other than the currently checked-out one are now pulled safely via a temporary git worktree.

**What's New**:

- Non-current branches are updated through a temporary worktree instead of switching branches in the main checkout
- Avoids touching the working tree and index of the current branch

**Impact**: Pulling behind branches no longer disrupts the current checkout or its uncommitted changes.
